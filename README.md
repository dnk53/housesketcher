# HouseSketcher 🏠✏️

**Interactive house design tool for Blender**

HouseSketcher is a Blender add-on that lets you sketch and build houses interactively with full control over dimensions and components.

---

## ✨ Features

- **Complete Building Generation** – Generate houses with foundation, walls, roof, slabs, windows and doors
- **Interactive Wall Editing** – Adjust start, length, height and width for each wall individually
- **Multiple Roof Types** – Gable, Shed (Front/Back) and Mansard roofs
- **Smart Slabs** – Choose between Interior, Exterior, Wall Guide or None for Boolean cutting
- **Real-time Updates** – Changes update instantly when you modify dimensions
- **Asymmetric Support** – Different heights, roof angles and overhangs on front/back
- **Mirror Function** – Easily mirror walls with correct insertion points

---

## 📦 Installation

1. Download the latest release from the [Releases page](https://github.com/dnk53/housesketcher/releases)
2. In Blender, go to `Edit` → `Preferences` → `Add-ons`
3. Click `Install...` and select the downloaded `.zip` file
4. Enable the add-on by checking the box next to "HouseSketcher"

---

## 🚀 Quick Start

1. Open Blender and press `N` to open the sidebar
2. Find the **HouseSketcher** tab
3. Click **Generate Building** to create your first house
4. Adjust dimensions in the panels to customize your design

---

## 📐 Main Dimensions

| Setting | Description |
|---------|-------------|
| **Length** | Building length (gable to gable) |
| **Width** | Building width (front to back) |
| **Height** | Interior wall height |
| **Roof Angle** | Angle of the lower roof |
| **Roof Type** | Gable, Shed Front, or Shed Back |

---

## 🧱 Wall Controls

Each wall can be individually edited:
- **Start** – Position where the wall begins
- **Length** – Wall length (0 = full length)
- **Height** – Wall height (0 = full height up to roof)
- **Width** – Wall thickness (0 = use global Wall Thickness)
